## DNSProxy Modern 4.11.1

This maintenance release removes the retired `dnsp-h2.c` from source
distributions and corrects an intermittent startup failure in protocol tests.

- **Legacy source.** The top-level Makefile drops the `dnsp-h2` target.
  Running `make` builds the supported `dnsp-modern` executable. The legacy
  source and its original build rules remain available in Git history.
  [Archived source](https://github.com/fantuz/DNSProxy/blob/c44f3e23ef4c59c000202a0092a939f7f4a391c4/dnsp-h2.c) · [PR #90](https://github.com/fantuz/DNSProxy/pull/90)
- **Protocol tests and benchmarks.** Loopback fixtures now select distinct
  ports for DNS, metrics and local upstreams. Previously, a fixture could
  select the same port for DNS and metrics, causing the resolver to exit
  before the HTTP/3 test began on Windows ARM64. The Python HTTP/2 test
  dependency `h2` advances from 4.3.0 to 4.4.1.
  [PR #89](https://github.com/fantuz/DNSProxy/pull/89)
- **Code scanning.** When GitHub's managed CodeQL scan publishes results, CI
  verifies the C/C++ analysis and saves the compiled resolver's SARIF report
  as the `dnsp-codeql-cpp` workflow artifact.
