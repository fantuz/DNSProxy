# Code of conduct

Everyone is welcome to ask questions, report a problem or contribute to DNSProxy.
Discuss the code and the evidence. Give people room to learn, credit their work
and respect their privacy. Harassment, threats, discrimination and publishing
another person’s private information are unacceptable.

Maintainers may hide or remove abusive content, lock a discussion or restrict
participation. To report abuse privately, use **Report content** on the relevant
GitHub item or contact GitHub Support through the reporting guide. Include a
link to the content when possible.
[GitHub Community Guidelines](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines) ·
[Reporting abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
